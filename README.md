  Vision Bridge —给 DeepSeek 接上视觉能力

  仓库： https://github.com/ghc5959/vision-bridge

  ---
  这是什么

  一个 MCP 服务。让没有视觉能力的 AI 模型能分析图片。

  原理：

  你给 AI 发一张图
      ↓
  Vision Bridge 把图发给视觉 API（GPT-4V / 通义千问VL / GLM-4V）
      ↓
  视觉 API 返回文字描述
      ↓
  AI 基于文字描述回答你

  AI = 大脑，视觉 API = 眼睛，Vision Bridge = 中间那根神经。

  ---
  能干什么

  ┌──────────────┬────────────────────────────┬─────────────────────┐
  │     场景     │          你做什么          │     AI 返回什么     │
  ├──────────────┼────────────────────────────┼─────────────────────┤
  │ 识别截图报错 │ 截图弹窗问"这是什么错"     │ 错误原因 + 修复建议 │
  ├──────────────┼────────────────────────────┼─────────────────────┤
  │ OCR 提取文字 │ 给表格图片，问"提取文字"   │ 完整文字内容        │
  ├──────────────┼────────────────────────────┼─────────────────────┤
  │ UI 分析      │ 给网页截图，问"什么配色"   │ 颜色值 + 布局描述   │
  ├──────────────┼────────────────────────────┼─────────────────────┤

  ---
  安装只需 3 步

  第 1 步：拿一个视觉 API 密钥

  ┌───────────────┬──────────┬────────────────────────────────────────┐
  │    服务商     │   价格   │                获取地址                │
  ├───────────────┼──────────┼────────────────────────────────────────┤
  │ 通义千问 VL   │ ¥0.01/张 │ dashscope.console.aliyun.com →API Key │
  ├───────────────┼──────────┼────────────────────────────────────────┤
  │ OpenAI GPT-4V │ $0.02/张 │ platform.openai.com →API Keys         │
  ├───────────────┼──────────┼────────────────────────────────────────┤
  │ 智谱 GLM-4V   │ ¥0.02/张 │ open.bigmodel.cn →API Keys            │
  ├───────────────┼──────────┼────────────────────────────────────────┤
  │ DeepSeek VL2  │ ¥0.01/张 │ platform.deepseek.com →API Keys       │
  └───────────────┴──────────┴────────────────────────────────────────┘

  ▎ 推荐通义千问，国内注册最方便、价格最低。

  第 2 步：装依赖

  git clone https://github.com/ghc5959/vision-bridge.git
  cd vision-bridge
  pip install -r requirements.txt

  第 3 步：配 Claude Code

  在 settings.json 加环境变量：

  "VISION_API_KEY": "sk-你的密钥",
  "VISION_API_URL": "https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions",
  "VISION_MODEL": "qwen-vl-max"

  在 .claude.json 的 mcpServers 加：

  "vision-bridge": {
    "command": "python",
    "args": ["C:/Users/你的用户名/vision-bridge/server.py"]
  }

  重启 Claude Code，生效。

  ---
  常见问题

  为什么不用 DeepSeek 自己的视觉？
  DeepSeek-V4 视觉能力有限。外挂专用视觉模型效果更好，还能随时换后端。

  图片传到哪了？
  直接发给视觉 API 服务商，不经过中间服务器。

  支持什么格式？
  PNG、JPG、GIF、WEBP、BMP。

  没 API 密钥能用吗？
  不能。需要至少一个视觉 API 密钥。推荐通义千问，价格最低
